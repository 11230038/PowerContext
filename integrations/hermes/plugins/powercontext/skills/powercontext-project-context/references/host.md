# Host binding

The native host owns Scope selection. Use current-request PowerContext routing metadata and implicitly bound tools; never independently select the Server default. Preserve the host's approval, human-review and session-eligibility requirements.

Set PLUGIN_ROOT to the absolute plugin root, two directories above this installed Skill's directory, when a command needs it. Follow actual native tool schemas and host approval.
